# Mensagem para colar no Codex ou no Claude Code

Abra esta pasta no Codex ou no Claude Code e cole o texto abaixo como primeira mensagem.

---

Você vai adaptar este e-commerce para a minha loja e colocá-lo no ar.

1. Leia, nesta ordem: `CLAUDE.md` (ou `AGENTS.md`), `kit/PLAYBOOK.md`, `kit/MAPA-DO-CODIGO.md` e `README.md`.
2. Os dados da minha loja estão em `kit/BRIEFING-DA-LOJA.md`. Se faltar algo obrigatório, me pergunte tudo de uma vez,
   numa lista curta.
3. Siga as fases do `kit/PLAYBOOK.md` na ordem. No fim de cada fase, me diga em poucas linhas o que ficou pronto e o que
   vem a seguir.
4. Quando precisar de uma conta ou chave, me guie pelo `kit/GUIA-DE-CHAVES.md`: diga onde clicar e o nome exato da
   variável.
5. Nunca invente preço, medida, material ou garantia. Nunca coloque chave secreta no código nem no Git.
6. Peça a minha confirmação antes de publicar no endereço oficial.

Fale comigo em português, de forma simples. Pode começar.
