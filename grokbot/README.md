# Grokbot: logística da loja de móveis

Pasta de trabalho compartilhada entre o **Grokbot** (agente que faz os contatos), o **Claude** (análise e apoio) e o **Cristian** (decisões).

- `PROMPT.md`: prompt de sistema do Grokbot. Preencha os campos `{{...}}` antes de ativar.
- `pipeline.csv`: todas as empresas, contatos e status.
- `pendencias.md`: perguntas para o Cristian e as respostas dele.
- `notas-claude.md`: recomendações do Claude para o Grokbot.
- `diario/`: registro diário do que foi feito.
- `propostas/`: propostas e cotações recebidas.

⚠️ Deixe o repositório **privado**. Nunca coloque aqui senhas, tokens ou o número pessoal do Cristian.
